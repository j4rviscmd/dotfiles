# readme-i18n-sync

## 概要

README.md（英語）の変更を各言語版READMEファイルに同期翻訳するスキル。

**基本原則:** README.mdを読み込み → 既存の言語別READMEファイルを検出 → 各言語に翻訳して上書き保存。

**開始時のアナウンス:**
「readme-i18n-syncスキルを使用してREADMEの多言語同期翻訳を実行します。」

## 前提条件

- プロジェクトルートで実行すること
- README.md（英語・ベース）が存在すること
- 1つ以上の言語別READMEファイル（README.{lang}.md）が存在すること

## ファイルパターン

- **ベースファイル**: `README.md`（英語・固定）
- **言語別ファイル**: `README.{lang}.md`
  - 例: `README.ja.md`, `README.zh.md`, `README.ko.md`, `README.es.md`, `README.fr.md`
- **新規作成**: しない（既存ファイルのみ更新）

## 翻訳除外ルール（自動判定）

以下は**翻訳せずそのまま維持**:

| 種類 | パターン | 判定方法 |
|------|----------|----------|
| コードブロック | ` ``` ... ``` ` | fenced block検出 |
| インラインコード | `` `code` `` | バッククォート検出 |
| URL | `https://...` | 正規表現 |
| パス | `/path/to/file` | 正規表現 |
| 画像パス | `![alt](path.png)` | Markdown記法 |
| HTMLタグ | `<table>...</table>` | タグ検出 |
| バッジ | `[![...](...)](...)` | パターンマッチ |
| Languagesセクション | `[English](README.md) \| [日本語](README.ja.md) ...` | 行パターンマッチ |

## 手順

### Step 1: 前提チェック

README.mdの存在確認と言語別READMEファイルの検出を行う。

**エラー条件**:
- README.mdが存在しない
- 言語別READMEファイルが存在しない

### Step 2: README.mdの読み込み

README.mdの内容を読み込み、翻訳の準備をする。

### Step 3: 各言語ファイルの翻訳

各言語ファイルに対して以下を実行:

1. **言語コードの抽出**
   - `README.ja.md` → `ja`（日本語）
   - `README.zh.md` → `zh`（中国語）
   - `README.ko.md` → `ko`（韓国語）
   - `README.es.md` → `es`（スペイン語）
   - `README.fr.md` → `fr`（フランス語）

2. **翻訳実行**
   - README.mdの内容をベースに翻訳
   - 翻訳除外ルールを適用
   - Languagesセクションは翻訳スキップ（そのまま維持）

3. **上書き保存**
   - 確認フローなし
   - 即座に上書き保存

### Step 4: 結果の報告

```text
README多言語同期翻訳が完了しました。

更新されたファイル:
- README.ja.md (日本語)
- README.zh.md (中国語)
- README.ko.md (韓国語)
- README.es.md (スペイン語)
- README.fr.md (フランス語)
```

## エラーハンドリング

| エラー状況 | 対応 |
|------------|------|
| README.md不在 | エラー表示して終了 |
| 言語別ファイル不在 | エラー表示して終了 |
| 翻訳エラー | 即座に停止、エラー内容を表示 |
| 書き込みエラー | 即座に停止、エラー内容を表示 |

**重要**: ある言語でエラーが発生した場合、全体を即座に停止する。部分的な更新は行わない。

## 翻訳のガイドライン

### 言語別の翻訳スタイル

| 言語 | スタイル |
|------|----------|
| 日本語 | 丁寧語（ですます調） |
| 中国語 | 簡体字 |
| 韓国語 | ハングル |
| スペイン語 | 標準スペイン語 |
| フランス語 | 標準フランス語 |

### 用語の扱い

- **技術用語**: 原語のまま維持（例: React, TypeScript, Tauri, npm）
- **コマンド**: 原語のまま維持（例: `npm install`, `git commit`）
- **パス**: 原語のまま維持（例: `src/app/`, `package.json`）

### Markdown記法の維持

- ヘッダーレベル（`#`, `##`, `###`）を維持
- リスト記法（`-`, `1.`）を維持
- テーブル記法を維持
- リンク記法を維持

## 注意事項

- 画像ファイル名（例: `app-image_en.png`）はそのまま維持
- 新しい言語を追加する場合は、手動で空の `README.{lang}.md` を作成してから実行
- 翻訳品質はAIの能力に依存するため、重要な変更は人間による確認を推奨

## 実行タイミング

- README.mdを更新した後
- リリース前のドキュメント整備時
